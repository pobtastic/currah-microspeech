00747: Parse Allophone Group
Used by the routine at ParseSpeechString.
Read a parenthesised allophone name from the speech string (for example "(AA)" or "(SH)"). Letters are normalised, checked against CharacterKeys, and summed; the sum selects an allophone from the parallel tables.
Input
HL Current string pointer
Output
A Mapped allophone
F Carry set if the group is invalid
Clear the running total that will identify the name.

Read letters until a closing parenthesis.
