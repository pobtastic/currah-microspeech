00056: Handle Interrupt
Any access to HandleInterrupt (including this opcode fetch) pages the μSpeech ROM in or out. The Spectrum IM1 handler lands here, so this ROM runs first. Every exit jumps back to HandleInterrupt, which pages the Spectrum ROM in and lets IM1 finish.
HandleInterrupt 00056 PUSH AF Preserve AF (this PUSH/POP pair is what Rockfall II checks for).
00057 POP AF
00058 DI Keep further interrupts out while the μSpeech ROM is paged in.
00059 PUSH HL Stash HL, AF, BC and DE on the stack.
00060 PUSH AF
00061 PUSH BC
00062 PUSH DE

The SP0256 is the speech-synthesiser chip. Read its status at 4096 (bit 0 is the inverted load request) and send the next queued allophone if the input buffer can take one.
FeedAllophone 00358 LD A,(4096) Read the SP0256 status from 4096.
00361 BIT 0,A Jump to ExitInterrupt if the chip's input buffer is full.
00363 JR NZ,ExitInterrupt
The manual notes that "the unit will remain silent until the first ENTER is pressed after a power up, a NEW, or after a 'report' has been printed at the bottom of the screen." On every interrupt that reaches this code where bit 7 of *ERR_NR is reset (an error code is waiting), this code empties the speech queue through EmptyQueue, so nothing is spoken until the ROM sets *ERR_NR back to 255; that happens when ENTER is pressed and on the editor's error paths (ED_ERROR and ED_FULL in the Spectrum ROM). The power-on and NEW cases are from the manual (chapter 2 also says any report other than OK has this effect).
