00843: Increment Pair
Used by the routine at HandleInterrupt.
Add one to two addresses DE bytes apart. Used to tick both keyboard-state timers.
Input
HL First address
DE Distance to the second address
IncrementPair 00843 PUSH HL Stash the first address on the stack.
00844 LD B,2 Set the update counter to 2.
IncrementPair_Loop 00846 INC (HL) Add one to this timer and move to the next.
00847 ADD HL,DE
00848 DJNZ IncrementPair_Loop Decrease the counter and loop back to IncrementPair_Loop until both timers are updated.
00850 POP HL Restore the first address from the stack.
00851 RET Return.
