0375: Check Memory
Used by the routines at HandleInterrupt and ParseSpeechString.
Compare the speech-buffer pointer with *RAMTOP. Carry is set when the pointer has dropped into the reserved workspace.
Input
BC Buffer pointer
Output
F Carry set if BC is below *RAMTOP
CheckMemory 0375 PUSH HL Stash HL on the stack.
0376 LD HL,($5CB2) Fetch *RAMTOP.
0379 OR A Compare *RAMTOP with the buffer pointer.
037A SBC HL,BC
037C CCF
037D POP HL Restore HL from the stack.
