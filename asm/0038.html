0038: Handle Interrupt
Any access to HandleInterrupt (including this opcode fetch) pages the μSpeech ROM in or out. The Spectrum IM1 handler lands here, so this ROM runs first. Every exit jumps back to HandleInterrupt, which pages the Spectrum ROM in and lets IM1 finish.
HandleInterrupt 0038 PUSH AF Keep AF unchanged.
0039 POP AF
003A DI Disable interrupts.
003B PUSH HL Stash HL, AF, BC and DE on the stack.
003C PUSH AF
003D PUSH BC
003E PUSH DE
The speech workspace is a short block just below *RAMTOP (low byte 57). A 48K machine uses FF57; a 16K machine uses 7F57.
003F LD HL,($5CB2) Fetch *RAMTOP.
0042 LD A,L Jump to ProbeWorkspace if the low byte is not 57.
0043 CP $57
0045 JR NZ,ProbeWorkspace
0047 LD A,H Jump to InstallWorkspace if this is a 48K machine.
0048 CP $FF
004A JR Z,InstallWorkspace
004C CP $7F Jump to InstallWorkspace if this is a 16K machine.
004E JR Z,InstallWorkspace
*RAMTOP is not the installed workspace yet.

The SP0256 is the speech-synthesiser chip. Read its busy flag at 1000 and send the next queued allophone if it is idle.
FeedAllophone 0166 LD A,($1000) Read the SP0256 status from 1000.
0169 BIT 0,A Jump to ExitInterrupt if the chip is still busy.
016B JR NZ,ExitInterrupt
016D LD A,($5C3A) Fetch *ERR_NR.
0170 RLA Call ResetBufferPointer if BASIC is not reporting an error.
0171 CALL NC,ResetBufferPointer
0174 CALL CompareBuffer Call CompareBuffer and jump to FeedAllophone_Write if there is something left to say.
0177 JR NZ,FeedAllophone_Write
0179 XOR A Silence the SP0256 and jump to ExitInterrupt.
017A LD ($1000),A
017D JR ExitInterrupt

FeedAllophone_Write 017F LD A,$06 Call ReadWorkspace for the next allophone.
