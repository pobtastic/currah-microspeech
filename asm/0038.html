0038: Handle Interrupt
Any access to HandleInterrupt (including this opcode fetch) pages the μSpeech ROM in or out. The Spectrum IM1 handler lands here, so this ROM runs first. Every exit jumps back to HandleInterrupt, which pages the Spectrum ROM in and lets IM1 finish.
HandleInterrupt 0038 PUSH AF Preserve AF (this PUSH/POP pair is what Rockfall II checks for).
0039 POP AF
003A DI Keep further interrupts out while the μSpeech ROM is paged in.
003B PUSH HL Stash HL, AF, BC and DE on the stack.
003C PUSH AF
003D PUSH BC
003E PUSH DE
The speech workspace is a short block at the top of the reserved area, between *RAMTOP and the UDGs (low byte 57). A 48K machine uses FF57; a 16K machine uses 7F57.
003F LD HL,($5CB2) Fetch *RAMTOP.
0042 LD A,L Jump to ProbeWorkspace if the low byte is not 57.
0043 CP $57
0045 JR NZ,ProbeWorkspace
0047 LD A,H Jump to InstallWorkspace if *RAMTOP is still the 48K power-on value (FF57).
0048 CP $FF
004A JR Z,InstallWorkspace
004C CP $7F Jump to InstallWorkspace if it is still the 16K power-on value (7F57).
004E JR Z,InstallWorkspace
*RAMTOP is not a power-on value; probe the speech workspace below it.
ProbeWorkspace 0050 LD A,$06 Call ReadWorkspace for the address of the queue head (index 06).
0052 CALL ReadWorkspace
0055 LD B,H Copy the workspace address to BC.
0056 LD C,L
0057 CALL CheckMemory Call CheckMemory and jump to InstallWorkspace to reinstall if the workspace is no longer protected by *RAMTOP.
005A JR C,InstallWorkspace
005C CALL ReadBufferPointer Call ReadBufferPointer.
005F CALL CheckMemory Call CheckMemory.
0062 CALL C,EmptyQueue Call EmptyQueue if the buffer pointer is at or below *RAMTOP.
0065 XOR A Call ReadWorkspace for the flags byte.
0066 CALL ReadWorkspace
0069 BIT 2,A Jump to ServiceSpeech if this is the second pass of this interrupt.
006B JR NZ,ServiceSpeech
006D SET 2,(HL) Flag that the next entry is the second pass.
006F POP DE Restore DE, BC, AF and HL from the stack.
0070 POP BC
0071 POP AF
0072 POP HL
Let the Spectrum's IM1 routine (MASK_INT) scan the keyboard first. When it returns, control goes to HandleInterrupt, which pages this ROM back in for the second pass.

Install abandons the interrupted program: MASK_INT returns to MAIN_1, re-entering the BASIC main loop with a fresh stack.

The Spectrum IM1 routine runs twice per frame (see ReturnToSpectrum), so take one off *FRAMES to compensate for the extra increment.

00C8 DEC (HL)

00CC DEC HL
00CD LD ($5C78),HL
Likewise add one to the repeat and delay counters in each half of *KSTATE, to compensate for KEYBOARD's extra decrement. (When a set is free these counters just drift upwards; KEYBOARD reloads them when a new key arrives.)

00D6 CALL IncrementPair Call IncrementPair.
00D9 DEC HL Move back to the five-call counters (5C01 and 5C05).

The SP0256 is the speech-synthesiser chip. Read its status at 1000 (bit 0 is the inverted load request) and send the next queued allophone if the input buffer can take one.
FeedAllophone 0166 LD A,($1000) Read the SP0256 status from 1000.
0169 BIT 0,A Jump to ExitInterrupt if the chip's input buffer is full.
016B JR NZ,ExitInterrupt
The manual notes that "the unit will remain silent until the first ENTER is pressed after a power up, a NEW, or after a 'report' has been printed at the bottom of the screen." On every interrupt that reaches this code where bit 7 of *ERR_NR is reset (an error code is waiting), this code empties the speech queue through EmptyQueue, so nothing is spoken until the ROM sets *ERR_NR back to FF; that happens when ENTER is pressed and on the editor's error paths (ED_ERROR and ED_FULL in the Spectrum ROM). The power-on and NEW cases are from the manual (chapter 2 also says any report other than OK has this effect).
016D LD A,($5C3A) Empty the speech queue (EmptyQueue) if BASIC is reporting an error (bit 7 of *ERR_NR reset).
0170 RLA

0177 JR NZ,FeedAllophone_Write
