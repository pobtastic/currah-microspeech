0447: Allophone Dictionary
Character-to-allophone lists used from ServiceSpeech_Lookup. Each entry is a key byte followed by one or more SP0256-AL2 allophone IDs. Bit 6 selects high intonation; the last ID has bit 7 set. The table starts with a dummy terminator (80) and ends on a key of 00. Each spoken list has an audio player. The raw AL2 set is on the Allophones page.
