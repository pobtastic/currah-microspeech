0354: Read Workspace
Used by the routines at HandleInterrupt, ParseSpeechString, TestKeysVariable, NormaliseCharacter, ReadBufferPointer, WriteBufferPointer, IsQueueEmpty and EmptyQueue.
Fetch a byte from the speech workspace. The block lives in the page of *P_RAMT, at low byte 57-index.
Input
A Workspace index
Output
A Byte at that index
HL Address of that index
ReadWorkspace 0354 LD HL,($5CB4) Fetch *P_RAMT.
The slot is 57 minus the index, in the page of *P_RAMT.
0357 LD L,A Calculate the address of this workspace index.
0358 LD A,$57
035A SUB L
035B LD L,A
035C LD A,(HL) Fetch the workspace byte.
035D RET Return.
