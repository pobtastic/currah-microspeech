Currah disassemblies
====================

A disassembly of the [Spectrum](https://en.wikipedia.org/wiki/ZX_Spectrum)
hardware from [Currah](https://en.wikipedia.org/wiki/Currah);

### 1983:
* [μSpeech](https://en.wikipedia.org/wiki/Currah)

Created using [SkoolKit](https://skoolkit.ca).

Browse the latest release:

* [Currah μSpeech disassembly](https://pobtastic.github.io/currah-microspeech/) (hexadecimal; mirror [here](http://skoolkit.arcadegeek.co.uk/microspeech/))
* [Currah μSpeech disassembly](https://pobtastic.github.io/currah-microspeech/dec/) (decimal; mirror [here](http://skoolkit.arcadegeek.co.uk/microspeech/dec/))

To build the current development version, first either install SkoolKit, or
make a clone of the [SkoolKit repository](https://github.com/skoolkid/skoolkit)
and point the environment variable SKOOLKIT_HOME at it. Then:

    $ cd microspeech
    $ utils/mkhtml.py

Disclaimer
----------

You will need to own the original hardware in order to disassemble the ROM.
